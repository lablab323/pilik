# ПИЛИК — приложение с сигналами времени для Android

Русскоязычный проект Android-приложения без рекламы, интернета и подписки.

## Возможности

- Одинарный или двойной короткий звуковой сигнал.
- Интервал: каждый час, каждые 30 минут, каждые 15 минут.
- **Отдельное расписание** для понедельника–пятницы и субботы–воскресенья.
- По умолчанию: будни **07:00–22:00**, выходные **10:00–22:00**.
- Начало периода включается, конец периода не включается.
- Вибрация, переключатель включения, кнопка проверки звука.
- Поддержка перезагрузки, смены часового пояса и системного времени.
- Нет разрешения на интернет и никакого сбора пользовательских данных.

## ВАЖНО: исходники, а не собранный APK

Этот ZIP содержит **проект**, а не готовый `.apk`. Для APK нужно запустить сборку Android через Android Studio или GitHub Actions.
В среде, где подготовлен проект, Android SDK не установлен, поэтому APK не был собран и фактически не проверен на телефоне.

## Как собрать на компьютере с Android Studio

1. Распакуйте ZIP.
2. В Android Studio откройте папку `Pilik` (Open project).
3. Убедитесь, что доступны Android SDK Platform 35, JDK 17 и Gradle 8.9.
4. Так как дистрибутив Gradle Wrapper не входит в ZIP, выберите **локальный Gradle 8.9** в настройках Gradle или сгенерируйте стандартный wrapper командой `gradle wrapper --gradle-version 8.9`.
5. В меню **Build → Build APK(s)** соберите отладочный APK.
6. Он появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Как собрать через GitHub Actions (без Android Studio)

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него **содержимое** папки `Pilik` целиком, включая скрытую `.github`.
3. Откройте вкладку **Actions** → **Сборка Пилик APK** → **Run workflow**.
4. После успешной сборки скачайте artifact **Пилик-APK** и распакуйте, внутри будет `app-debug.apk`.
5. Откройте APK на телефоне и разрешите установку из этого источника (если Android запросит).

## Как настроить на телефоне

1. В приложении разрешите **уведомления**.
2. Нажмите **Разрешить точные сигналы** и активируйте разрешение **Будильники и напоминания**.
3. Разрешите работу в фоне, если система вашего телефона ограничивает приложение.
4. По умолчанию утренних сигналов в субботу и воскресенье в 07:00 и 08:00 **не будет** — первые в 10:00.

Сигналы используются через системные уведомления Android, поэтому громкость уведомлений, пользовательские настройки канала уведомлений, беззвучный режим и «Не беспокоить» могут влиять на звук. На Android 12+ без разрешения на точные будильники сигнал может задерживаться. Даже с разрешениями агрессивное энергосбережение производителя может менять фактическую точность.

## Структура

- `MainActivity.java` — экран и сохранение настроек.
- `AlarmScheduler.java` — вычисление ближайшего сигнала и системный AlarmManager.
- `ChimeReceiver.java` — уведомление со звуком.
- `RescheduleReceiver.java` — повторное планирование после перезагрузки и смены времени.
- `res/raw/` — два оригинальных коротких звука.
- `.github/workflows/build-apk.yml` — сборка APK в GitHub.

Приложение демонстрационное: требуется финальная сборка и проверка на настоящем Android-устройстве.
